What It Does

🧹

Data Preprocessing

Handles missing values, encodes categorical features, and normalises numeric columns for clean model input.

🔧

Feature Engineering

Creates derived features like attendance rate and assignment completion ratio to improve model signal.

🤖

Multi-Model Evaluation

Trains and benchmarks Logistic Regression, Random Forest, SVM, and XGBoost — picks the best performer.

📈

87% Accuracy

Random Forest achieved 87% accuracy on the test set with solid precision and recall across grade tiers.

ML Pipeline

1

Data Collection

Historical student records — grades, attendance, assignments, demographics.

2

Preprocessing

Handle nulls, encode categoricals, scale numerics with StandardScaler.

3

Feature Engineering

Create meaningful derived features, drop low-importance columns.

4

Model Training

Train LR, RF, SVM, XGB with cross-validation on 80% training split.

5

Evaluation

Accuracy, precision, recall, F1, confusion matrix on 20% test split.

Challenges & Learnings

😤 Challenges

  • Class imbalance — far more average students than failing/exceptional ones.
  • Deciding which features to keep vs. drop without overfitting the training data.
  • Hyperparameter tuning was time-consuming without GPU acceleration.
  • Interpreting model results in a meaningful way for non-technical educators.

💡 Learnings

  • SMOTE oversampling helped significantly with class imbalance.
  • Feature importance plots from Random Forest revealed attendance as the strongest predictor.
  • Cross-validation is non-negotiable — single train/test splits can be highly misleading.
  • Explainability matters as much as accuracy when presenting to stakeholders.
