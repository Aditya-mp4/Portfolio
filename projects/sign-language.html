What It Does

👁️

Gesture Recognition

OpenCV processes camera frames in real-time; classifier identifies ASL/ISL hand signs with high accuracy.

🔊

Speech Synthesis

Recognised signs are mapped to text, then converted to natural-sounding speech via TTS synthesis.

📱

Mobile App

Flutter frontend provides a clean, accessible mobile interface — camera feed + live transcription view.

🌐

Flask Backend

Python + Flask API handles all CV processing server-side, keeping the mobile client lightweight.

Challenges & Learnings

😤 Challenges

  • Similar-looking signs (e.g. "A" vs "S" in ASL) causing misclassification.
  • Latency across the Python → Flask → Flutter pipeline was initially too high for real use.
  • Background clutter confusing the hand segmentation in complex environments.
  • Building a training dataset for regional sign language variants was time-consuming.

💡 Learnings

  • Background subtraction + skin tone segmentation dramatically improved accuracy.
  • Caching frequently used sign-to-text mappings on the client cuts round-trip latency.
  • Assistive tech needs ruthlessly simple UX — every extra tap is a barrier.
  • Cross-platform development with Flutter saved significant time vs native iOS/Android.
