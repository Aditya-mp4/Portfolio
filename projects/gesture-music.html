What It Does

👋

Real-Time Hand Tracking

Uses MediaPipe to detect 21 hand landmarks per frame with sub-20ms latency.

🎵

Gesture → MIDI Mapping

Custom logic maps finger combinations and hand positions to musical notes and controls.

🎛️

DAW Integration

MIDI signals feed directly into any DAW — Ableton, FL Studio, GarageBand — no plugins needed.

🔄

Iteratively Refined

Multiple test sessions to tune gesture accuracy, reduce false positives and control drift.

def get_fingers_up(hand_landmarks):
  fingers = []
  tips = [8, 12, 16, 20] # index, middle, ring, pinky
  for tip in tips:
    fingers.append(hand_landmarks[tip].y < hand_landmarks[tip - 2].y)
  return fingers

def map_to_midi(fingers, hand_y):
  note = SCALE[fingers.count(True)] # fingers up → note

Challenges & Learnings

😤 Challenges

  • Gesture jitter — tiny hand tremors caused constant false MIDI triggers.
  • Lighting variance made MediaPipe confidence drop in low/high light.
  • MIDI latency spikes when CPU was under load from OpenCV processing.
  • Designing an intuitive gesture vocabulary that felt natural to play.

💡 Learnings

  • Debounce buffers and confidence thresholds dramatically reduce jitter.
  • Threading OpenCV capture separately from MIDI output cuts latency by ~40%.
  • Human-centered design matters — musicians need to learn the system in minutes.
  • Iterative testing sessions are the only way to truly validate gesture UX.
