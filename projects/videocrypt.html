What It Does

🔐

Role-Based Auth

Viewer, Uploader, and Admin roles with JWT — each sees only what they're permitted to access.

📺

Secure Streaming

Videos are served via protected routes — no direct file access, proper token validation on every request.

🗄️

Dual DB

MongoDB handles flexible video metadata; SQL manages structured user data and permissions.

👥

Team Built

Collaborative delivery — Git workflow, code reviews, feature branches, and integration testing.

Challenges & Learnings

😤 Challenges

  • Syncing MongoDB and SQL — keeping user permissions consistent across both databases.
  • Video streaming performance — buffering and chunked delivery optimisation.
  • JWT token expiry edge cases causing silent auth failures in the frontend.
  • Coordinating team Git workflow without stepping on each other's code.

💡 Learnings

  • Middleware-based auth validation scales far better than per-route checks.
  • HTTP range requests are essential for smooth video streaming UX.
  • A clear API contract between frontend and backend prevents most integration bugs.
  • Code review culture improves quality dramatically — even in small teams.
