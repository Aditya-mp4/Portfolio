The story

CodeSquadz (AppSquadz) was my first real taste of building software as part of a team rather than alone at 1am chasing a side-project idea. We built VideoCrypt, a full-stack secure video streaming platform, and my corner of it was the MERN stack — MongoDB, Express, React, and Node — while the rest of the team owned other pieces of the same system in parallel.

Role-based authentication was the part that made me slow down and actually think about security instead of just shipping a feature. Getting SQL integration to sit alongside MongoDB meant reconciling two very different ways of thinking about data, and role-based access meant every part of the system needed to ask "who's allowed to do this" before it did anything at all.

What this internship really taught me, though, was the difference between building something solo and building something with a team on a deadline. A solo project lives and dies by whatever I decide to prioritize that week. Here, my code had to integrate cleanly with everyone else's, on a schedule none of us fully controlled on our own. Communication became as much a part of the job as the code itself — syncing on what an endpoint should return, agreeing on how auth roles were structured, staying out of each other's way in the same codebase.

VideoCrypt is still the project I point to when someone asks what "collaborative" actually means in practice, past a resume bullet point. This page is really about what the internship itself taught me — for what we actually built, the project page has the rest.

Challenges & learnings

😤 Challenges

  • Reconciling role-based access rules with a MongoDB-first schema.
  • Coordinating features with teammates on a shared deadline without stepping on each other's work.
  • Integrating SQL alongside MongoDB within the same platform.

💡 Learnings

  • Security has to be designed in from the start, not bolted on after.
  • Clear communication about what an endpoint returns matters as much as the code behind it.
  • Team deadlines force different tradeoffs than a solo project ever does.
